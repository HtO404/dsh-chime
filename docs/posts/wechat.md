# AI 干活的时候，你不用再盯着屏幕了

> 这篇文章介绍一个我写的小工具，免费、开源、装完就忘——但它真的能帮你省下很多「盯着进度条」的时间。

---

你有没有过这样的经历？

给 AI 发了一个 20 分钟的大任务，然后切走去看视频、去写代码、去处理别的事。

20 分钟后你回来——

任务早就跑完了。

**而你永远不知道，它是什么时候跑完的。**

于是你养成了一个习惯：隔一会儿就切回去，刷新一眼任务列表。

这个习惯本身，就是最大的时间黑洞。

## 于是我做了一个小插件

它叫 **dsh-chime**，给 [DeepSeek Harness](https://github.com/deepseek-ai/dsh)（DSH）的网页界面加一个「任务完成提示音」。

**任务跑完的那一刻，它替你喊一嗓子。**

更关键的是——**页面挂在后台标签页，声音也照常响。**

![banner](【图片1：docs/banner.png】)

## 就一句话的事

你发任务，切走，等声音。

听到了，回来收结果。

听不到，说明还没跑完——不用切回来，不用刷进度，不用猜。

**把盯着任务列表的那双眼睛，还给你自己。**

## 它有什么

- 🔔 **后台也响**：用 Web Audio 播放，页面切走、标签页挂后台，照常响
- 🎵 **10 个精选预设音**：开箱即用，首次运行自动装好
- 📂 **自定义声音**：wav / mp3 / ogg，换成你自己的声音
- 🔊 **音量自由**：0~100% 滑杆，松手即试听
- ⚙️ **设置就在「设置 → 插件」**：一处配置，处处生效
- ♻️ **重启自动拉起**：随 DSH 自启，装一次，以后不用管

![panel](【图片2：docs/panel.png】)

## 怎么装

如果你在用 DSH，一条命令：

```powershell
dsh plugin --profile web add @hto404/dsh-chime
```

然后重启 DSH，打开网页界面，进 **设置 → 插件 →「🔔 任务完成提示音」**，选个喜欢的声音，完事。

（首次如果没听到声音，点一次「测试声音」解锁浏览器自动播放就行。）

## 它怎么知道任务完成了

原理不复杂：

Host 端监听 agent 状态，任务完成就进队列；浏览器每 2 秒问一次「有通知吗」，有就用 Web Audio 播放。

**它只响根任务**——一个长任务里十几个子任务跑完不会吵你，只有最终结果出来才报信。

## 两个小细节

1. **想换预设**：把 mp3/wav/ogg 丢进 `~/.dsh/dsh-chime/sounds`，重启插件就出现在列表里。
2. **内置音效**来自 Mixkit（免费可商用），协议 Apache-2.0，随便用。
